|-------|------|---------------|

## 🗺️ Member Map Registration

Once you've accepted the invite, create a file in the `/membersmap` directory:

**Filename:** `YOUR_GITHUB_USERNAME.md` (or `.json`)

**Example:**
```markdown
# Farhan Ashraf

- **Location:** Lahore, Pakistan
- **Interests:** Kubernetes Security, DevSecOps, Falco
- **GitHub:** [@farhanashrafdev](https://github.com/farhanashrafdev)
- **LinkedIn:** [linkedin.com/in/farhanashrafdev](https://linkedin.com/in/farhanashrafdev)

## Why I Joined
I'm passionate about securing cloud-native infrastructure and contributing to CNCF projects.
```

Submit a **Pull Request** with your file. Once merged, you're automatically promoted to **Member**! 🎉

## ⚙️ How the Automation Works

### Invitation Flow
1. You open an issue using the **"Request Invitation"** template.
2. GitHub Actions extracts your username and sends an org invite.
3. You're added to the **Newbie** team automatically.
4. A welcome comment is posted with next steps.

### Promotion Flow
1. You submit a PR adding your file to `/membersmap`.
2. When merged, GitHub Actions promotes you to **Member** team.
3. A congratulations comment celebrates your achievement!
