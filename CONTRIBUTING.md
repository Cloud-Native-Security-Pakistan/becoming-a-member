# Contributing to Cloud Native Security Pakistan

Thank you for your interest in contributing! We welcome contributions from everyone.

## 🚀 Quick Start

1. **Fork** this repository
2. **Create a branch** for your changes
3. **Make your changes** and commit with clear messages
4. **Submit a Pull Request**

## 📋 Types of Contributions

- **Member Profiles** — Add yourself to `/membersmap`
- **Documentation** — Improve README, guides, or templates
- **Workflows** — Enhance GitHub Actions automation
- **Bug Fixes** — Report or fix issues

## 💡 Guidelines

- Keep PRs focused on a single change
- Follow existing code style and formatting
- Write clear commit messages (e.g., `feat: add new member template`)
- Be respectful in discussions

## 🎮 Progression

Your contributions unlock higher team levels:

| PRs Merged | Team Level |
|------------|------------|
| 0 | Newbie |
| 1 (membersmap) | Member |
| 1+ (other) | Contributor |
| 3+ | Advanced Contributor |

## ❓ Questions?

Open an [issue](https://github.com/Cloud-Native-Security-Pakistan/become-a-member/issues) or reach out on [WhatsApp](https://chat.whatsapp.com/F5Hf1ZwI22TK6EcV6zz4wo).
